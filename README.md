# Облачный мур — готовый сайт для GitHub Pages

Сайт работает без сборки и серверной части. Все пути относительные: подходит для https://USERNAME.github.io/REPOSITORY/.

## Как опубликовать
1. Создайте репозиторий на GitHub.
2. Загрузите содержимое папки cloud-mur: index.html, style.css, script.js, все изображения .webp и .nojekyll. index.html должен находиться в корне репозитория.
3. Откройте Settings → Pages → Build and deployment.
4. Выберите Deploy from a branch, ветку main, папку / (root), нажмите Save.
5. Дождитесь публикации. Адрес появится в разделе Pages.

Для локального просмотра откройте index.html в браузере. Можно также запустить `python3 -m http.server 8000` из этой папки и открыть http://localhost:8000.

## Что работает
Адаптивные версии для телефона, планшета и компьютера; мобильное меню; цветные и незакрашенные примеры; увеличение изображений; вопросы; диалог бронирования с копированием сообщения и переходом в Telegram; плавное движение с учётом настройки уменьшения анимаций.

## Бронирование
Кнопка подготавливает сообщение для ручной отправки. Сайт не сохраняет заявки и не подтверждает бронь автоматически. Предоставлена только ссылка на канал https://t.me/Di_Art10: отдельный личный контакт не выдуман. Для прямого обращения замените ссылку в диалоге на свой контакт или бота; ссылку на канал в остальных разделах сохраните.

## Что уточнить перед продажами
Цена, бумага, комплектация и доставка пока не заявлены. Срок указан ориентировочно: Новый год, начало 2027 года. Показано 3 пары реальных предоставленных цветных/незакрашенных изображений; заявленные 36 — объём будущего выпуска, а не количество загруженных на сайт файлов. Названия карточек — редакционные подписи. Макеты незакрашенных страниц показываются целиком, включая поля.

## Изменения
Тексты и ссылки: index.html. Палитра, размеры и адаптивы: style.css. Взаимодействия: script.js. Изображения: файлы .webp в корне. Шрифты Cormorant Garamond, Manrope и Marck Script подключены через Google Fonts; при отсутствии интернета есть системные замены. Изображения оптимизированы в WebP, исходные загрузки не изменены.

Перед коммерческой публикацией проверьте права на изображения и персонажей.

## Обновление: больше воздуха и правовой подвал
Отступы между разделами увеличены отдельно для компьютера, планшета и телефона. Порядок галереи: романтика, небожители, Мао-Мао; в блоке о проекте — предоставленная Рокси. Макет-изображение иллюстрирует дизайн и не является скриншотом HTML; положение декора и шрифты могут отличаться.

В подвале работают ссылки на четыре отдельные страницы: сведения о продавце, условия бронирования, оплата/доставка/возврат, политика обработки персональных данных. Это подготовленная структура, а не подтверждение юридической готовности бизнеса. Страницы с незаполненными данными явно помечены как шаблоны и имеют noindex. Перед публикацией заполните все квадратные скобки: фактический статус, полное имя/наименование, применимые регистрационные сведения, контакты, адреса, правила продаж и фактическую обработку данных. Для самозанятого не указывайте выдуманный ОГРНИП.

Нет кнопки оплаты, автоматического подтверждения брони, форм сбора персональных данных, собственной аналитики и cookies. Ссылка на Telegram-канал не заменяет личный контакт продавца. GitHub Pages и Telegram не подтверждают соблюдение требований локализации данных: перед запуском обработки проверьте подходящую инфраструктуру и обязательства оператора. Шрифты переведены на системные замены для исключения запросов к Google Fonts; при необходимости разместите лицензированные шрифты локально.

Основания для подготовки: сведения Роспотребнадзора о п. 19 Правил № 2463 и дистанционной продаже; ст. 26.1 Закона РФ «О защите прав потребителей»; ст. 18.1 Федерального закона № 152-ФЗ. Использованные ссылки:

Для полноценной юридической финализации нужны реальные сведения владельца и условия работы. Визуальное браузерное тестирование в текущей среде недоступно; проверены синтаксис JavaScript и локальные ссылки. Скриншоты не заявлены как результат тестирования.


## Версия без папок
Все изображения находятся рядом с index.html. В HTML и JavaScript используются ссылки вида cover.webp и maomao-line.webp — без assets/ и без начального слеша. Эти пути работают также на GitHub Pages в репозитории с собственным названием.

Распакуйте архив, откройте репозиторий → Add file → Upload files и перетащите ВСЕ распакованные файлы одновременно. Не загружайте сам ZIP вместо файлов. index.html, style.css, script.js, правовые страницы и все .webp должны оказаться на одном уровне, в корне репозитория. Замените старые файлы при загрузке. Затем Settings → Pages → Deploy from a branch → main → / (root) → Save.


Подписи галереи: «Любовь с кончиков пальцев», «Благословение небожителей», «Монолог фармацевта». Те же названия отображаются при увеличении страниц.
