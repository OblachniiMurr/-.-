2. Работа сайта

В текущей версии сайт не содержит форм отправки данных, личного кабинета, платежей, рекламных пикселей или подключённой аналитики. Текст сообщения для бронирования формируется в браузере. По нажатию кнопки он копируется в буфер обмена; отправка происходит только вручную пользователем в Telegram.

Код сайта не устанавливает собственные cookies и не использует localStorage для профилирования посетителей. Поэтому в этой версии нет отдельного баннера согласия на аналитические cookies.

Планируемый хостинг — GitHub Pages. При открытии сайта инфраструктура хостинга получает технические сведения о запросе, включая IP-адрес. Условия такой обработки определяются также документами поставщика хостинга. Шрифты в этой версии используются из локальных системных наборов, без запросов к Google Fonts.

При самостоятельном переходе в Telegram и отправке сообщения обработка производится также этим сервисом по его правилам. Настоящая страница не является согласием на трансграничную передачу и не подтверждает выполнение требований к локализации данных.
